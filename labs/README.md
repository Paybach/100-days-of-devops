# DevOps Labs

Use these guided workbooks alongside the roadmap. Each lab is intentionally
small enough to complete in one or two sessions.

| Lab | Best time to start | Outcome |
| --- | --- | --- |
| [01: Linux health check](lab-01-linux-health-check.md) | Days 004-010 | Write and test a basic system-health script |
| [02: Git collaboration](lab-02-git-collaboration.md) | Days 014-016 | Practice branching, merging, and pull requests |
| [03: Containerize an app](lab-03-containerize-an-app.md) | Days 021-030 | Package and run a small web app with Docker |
| [04: Terraform lifecycle](lab-04-terraform-lifecycle.md) | Days 044-050 | Practice repeatable infrastructure changes |
| [05: Kubernetes rollout](lab-05-kubernetes-rollout.md) | Days 062-074 | Deploy, update, inspect, and roll back an app |

Tick the boxes as you work and commit the completed workbook with your notes.
