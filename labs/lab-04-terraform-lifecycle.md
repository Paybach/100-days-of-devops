# Lab 04: Terraform Lifecycle

## Goal

Use Terraform to create a simple local file and observe the workflow before
provisioning cloud resources.

## Tasks

- [ ] Create a folder named `terraform-local-lab`.
- [ ] Add a Terraform configuration using the `local_file` resource.
- [ ] Run `terraform init`.
- [ ] Run `terraform fmt`.
- [ ] Run `terraform validate`.
- [ ] Run `terraform plan`.
- [ ] Run `terraform apply`.
- [ ] Change the file contents and inspect a second plan.
- [ ] Run `terraform destroy`.

## Reflection

- Why should you inspect a plan before applying it?
- Which Terraform-generated files should be committed or ignored?
