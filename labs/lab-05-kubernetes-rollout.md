# Lab 05: Kubernetes Rollout

## Goal

Deploy a container, inspect it, update it, and roll it back.

## Tasks

- [ ] Start a local Kubernetes cluster.
- [ ] Create a deployment using the `nginx` image.
- [ ] Expose the deployment with a service.
- [ ] Inspect pods, deployments, and services with `kubectl`.
- [ ] Update the image tag and watch the rollout.
- [ ] Inspect rollout history.
- [ ] Roll back to the previous version.
- [ ] Delete the practice resources.

## Reflection

- What does Kubernetes do when one pod fails?
- Why are rollbacks useful during deployments?
