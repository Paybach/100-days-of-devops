# Lab 02: Git Collaboration

## Goal

Practice a safe branch-based workflow without changing your main branch until
your work is ready.

## Tasks

- [ ] Create a branch with `git switch -c practice/git-collaboration`.
- [ ] Add a short file named `git-practice.md`.
- [ ] Commit the new file.
- [ ] Switch back with `git switch main`.
- [ ] Merge the branch with `git merge practice/git-collaboration`.
- [ ] Inspect the history with `git log --oneline --graph --all`.
- [ ] Push the updated `main` branch.

## Stretch Task

Repeat the exercise through a GitHub pull request instead of merging locally.
