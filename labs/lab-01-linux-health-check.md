# Lab 01: Linux Health Check

## Goal

Write a small Bash script that reports useful machine-health information.

## Tasks

- [ ] Create `health-check.sh`.
- [ ] Add `#!/usr/bin/env bash` as the first line.
- [ ] Print the current date and hostname.
- [ ] Print disk usage with `df -h`.
- [ ] Print memory usage with `free -h`.
- [ ] Print the five busiest processes.
- [ ] Run the script and record the output.
- [ ] Add one improvement of your own.

## Reflection

- Which metric would help you spot a problem first?
- How would you schedule this script to run automatically?
