# Project 02: Container Delivery

## Brief

Package a small web app and automate its quality checks.

## Deliverables

- [ ] Create a small web page or API.
- [ ] Add a `Dockerfile`.
- [ ] Add a `compose.yaml` file if the app needs more than one service.
- [ ] Add a container health check.
- [ ] Run the container locally and document the commands.
- [ ] Add a GitHub Actions workflow that builds the image.
- [ ] Explain how you would promote the image to staging and production.

## Stretch Task

Publish the image to a container registry using versioned tags.
