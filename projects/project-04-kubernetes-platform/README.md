# Project 04: Kubernetes Platform

## Brief

Deploy your containerized app to a local Kubernetes cluster.

## Deliverables

- [ ] Add deployment and service manifests.
- [ ] Add readiness and liveness probes.
- [ ] Add CPU and memory requests and limits.
- [ ] Move configuration into a ConfigMap or Secret.
- [ ] Perform an update and document the rollback command.
- [ ] Add an ingress or explain how traffic reaches the app.
- [ ] Document the deployment steps.

## Stretch Task

Package the manifests as a Helm chart.
