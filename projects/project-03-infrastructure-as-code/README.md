# Project 03: Infrastructure as Code

## Brief

Create a repeatable Terraform environment locally or with a cloud provider.

## Deliverables

- [ ] Add a formatted Terraform configuration.
- [ ] Use input variables and outputs.
- [ ] Separate reusable infrastructure into at least one module.
- [ ] Document `init`, `plan`, `apply`, and `destroy`.
- [ ] Explain where state is stored and how you would protect it.
- [ ] Add an architecture diagram.
- [ ] Add a short cost and cleanup note.

## Safety Note

Destroy cloud practice resources when you finish and check the provider console
to confirm that they are gone.
