# Day 001: DevOps Mindset

## Goal

Understand how DevOps connects people, process, and tooling to deliver reliable
software in small, repeatable steps.

## Notes

- DevOps is a way of working, not a single tool.
- Fast feedback makes changes safer and easier to improve.
- Automation, observability, and shared ownership reduce avoidable friction.

## Hands-on Work

Pick an application you use regularly. Sketch the path from a developer making
a code change to a user receiving the update. Include testing, deployment,
monitoring, and rollback.
